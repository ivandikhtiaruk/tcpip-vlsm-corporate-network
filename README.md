##  Опис проєкту
Проєкт присвячено комплексній модернізації та проектуванню ієрархічної системи IP-адресації для розподіленої корпоративної мережі з центральним офісом у м. Київ (HQ) та трьома регіональними філіями у містах Львів, Одеса і Харків.

Попередня топологія страждала від нераціонального використання адресного простору та ризиків виникнення IP-конфліктів. У рамках проєкту здійснено перехід на приватний адресний блок **172.16.0.0/16** (RFC 1918) із застосуванням технології масок змінної довжини (**VLSM**) та безкласової маршрутизації (**CIDR**).

### Ключові інженерні рішення:
- **Оптимізація підмереж (VLSM):** Кожен підрозділ отримав адресний простір, розрахований під точну кількість хостів із резервом росту 30–50%.
- **Канали Point-to-Point (WAN):** Для міжвузлових лінків використано маски `/30` (економія 99% адрес у порівнянні з класичними `/24`).
- **Сегментація трафіку (VLAN):** Реалізовано схему *Router-on-a-Stick* (802.1Q) для розділення трафіку серверної ферми, розробників, персоналу та керування.
- **Динамічна маршрутизація:** Налаштовано **OSPFv2** (Area 0) з сумаризацією маршрутів на центральному маршрутизаторі.
- **Трансляція адрес та автоконфігурація:** Впроваджено **NAT/PAT (Overload)** для виходу в Інтернет та **DHCP Relay** для централізованої роздачі адрес.
